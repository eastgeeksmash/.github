## 💡 About Us
**East Geek Smash(EGS)** はスマブラを始めとするゲームのオフ大会運営&配信クルーです。

## 🚀 What We Do
- **Tournament Organizing**: `EGS Cup` や `Weekly Smash Party (スマパ！)` などの大会企画・運営
- **Live Broadcasting**: YouTube/Twitchでのライブ配信、実況解説の提供
- **Production Tech**: 配信をよりリッチにするオーバーレイ（StreamControl等）のカスタマイズや、自動化ツールの開発
- **Consulting**: 有志大会への運営・配信ノウハウの共有と技術協力
