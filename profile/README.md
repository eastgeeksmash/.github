## 💡 About Us
**East Geek Smash (EGS)** は、『大乱闘スマッシュブラザーズ』シーンを中心に活動する**配信クルー・大会運営団体**です。

私たちは「スマブラコミュニティに携わる人が活躍できる場を作り、人に対して付加価値を付け、還元する」ことを理念としています。技術と情熱を融合させ、高品質な大会運営とライブ配信、そしてそれらを支えるツールの開発を行っています。

## 🚀 What We Do
- **Tournament Organizing**: `EGS Cup` や `Weekly Smash Party (スマパ！)` などの大会企画・運営。
- **Live Broadcasting**: YouTube/Twitchでのハイエンドなライブ配信、実況解説の提供。
- **Production Tech**: 配信をよりリッチにするオーバーレイ（StreamControl等）のカスタマイズや、自動化ツールの開発。
- **Consulting**: 有志大会への運営・配信ノウハウの共有と技術協力。
